# Путь по CRM: план реализации

Структура и интеграция согласованы пользователем ответом «да» 2026-09-08.
Выполнение локально в текущем проекте; без коммитов, push, публикации и зависимостей.

**Цель:** интерфейсная история ElevenHouse на существующем звёздном фоне, с текущими коммерческими блоками и синим тоннелем в финале.

**Архитектура:** существующий CosmicHero сохраняет lifecycle и canvas, получает режим фонового слоя. Новая история находится в естественном document flow со sticky-главами. Отдельный адаптер передаёт CosmicScene прогресс существующей сцены и дельты пролётов. CSS интерфейсов изолирован в `.eh-journey`.

**Стек:** React/TypeScript, native scroll/RAF/ResizeObserver, текущий Three.js.

## Ограничения

- Не менять шейдеры, геометрию, материалы, цвета и motion helpers существующего фона.
- Первый заголовок: «Вся практика астролога» слева вверху, «в одном приложении» справа внизу; существующая композиция финала — референс.
- Реальные DOM/SVG элементы из архива, адаптированные к типизированным компонентам. Не импортировать приложение и global CSS из архива целиком.
- Данные вымышленные и согласованные между сценами; все действия демонстрационные и локальные.
- Тарифы, отзывы и FAQ сохраняются перед финальным тоннелем.
- Desktop/mobile, reduced motion, keyboard, reverse scroll, restoration и cleanup обязательны.
- Исходный сбой suite `experiments/natal-dial/src/renderer/physicalDial.test.ts` не исправлять в рамках этого изменения.
