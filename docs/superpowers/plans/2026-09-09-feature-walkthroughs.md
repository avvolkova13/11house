# Понятное знакомство с возможностями ElevenHouse

Цель: выполнить уточнение пользователя — в каждой из девяти возможностей объяснить «что, зачем, как» на анимированных фрагментах исходной CRM. Вход, меню выбора, Hero, фон, коммерческие блоки и финал уже одобрены и сохраняются. Работа только локально, без коммитов, публикации и зависимостей.

Направление: слева короткое объяснение текущего действия и его пользы, справа исходный фрагмент CRM с последовательным изменением данных. На телефоне объяснение располагается над интерфейсом. Пример проходит на Марине Соколовой; сценарии можно смотреть независимо в любом порядке. Пользователь уже явно запросил этот формат исправления; отдельная смена дизайн-направления не требуется.

1. `featureStories.ts`: сценарии, короткие объяснения, результат и длительность каждого шага. Клиенты — данные/история/заметка/сообщение; расчёты — данные/четыре системы; календарь — встреча/выбор времени/подтверждение; услуги — заполнение/карточка; консультации — подготовка/материалы; сопровождение — запись/ответ; AI — цепочка/черновик/подтверждение; контент — текст/расписание/трактовки; практика — оплата/профиль.
2. `featurePlayback.ts`, тесты: детерминированная шкала времени, посимвольный ввод, конец без зацикливания, видимость высокого фрагмента. Проверить пустое → промежуточное → завершённое состояние.
3. `FeatureWalkthrough.tsx`, локальный CSS: один проигрыватель, управление паузой/повтором/шагами, остановка при скрытии вкладки или уходе фрагмента из области чтения, cleanup RAF/observer/listeners. Reduced motion — статичные завершённые действия с ручным переключением. Один активный сценарий, без видео, сети и изменения фонового renderer.
4. `SourceFragments.tsx`: добавить необязательное управляемое состояние к существующим JSX-фрагментам. Сохранять источник компонентов, нативные элементы и текущие стили; показывать заполнение/нажатие/подтверждённый результат. SVG-расчёты мемоизировать, чтобы не перестраивать их на каждом кадре. Дополнительный редактор публикации — из `app/content.jsx → PostEditor`.
5. `ProductExperience.tsx`: заменить только содержимое выбранной возможности новым проигрывателем. Карточки выбора, их тексты и путь входа сохранить.
6. Проверка: рендер всех шагов в начале/середине/конце; тесты переходов, сборка, браузерный проход клиент/календарь/AI и узкий экран, пауза/повтор/reduced motion. Проверить отсутствие внешних действий, запрещённых подписей, горизонтального overflow и ошибок консоли.
