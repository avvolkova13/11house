# Continuous Hero Product Tunnel — design specification

## Approved direction

Architecture A: один непрерывный sticky/WebGL экран от первого заголовка до завершения перехода «хаос → система».

## Narrative order

Каждый заголовок появляется ровно один раз:

1. `Вся ваша практика`
2. `В одном пространстве`
3. `ElevenHouse`
4. `Хотя подождите.`
5. `У вас ведь уже есть система.`
6. `Вот она.`
7. `Мы просто собрали вашу работу обратно.`

Первые три состояния используют существующую typography-fragment choreography. Состояния 4–6 переходят к Mesh3D-подобной композиции: крупный текст, центральная реальная product-плоскость, движение по z-оси и пересечение слоёв текста и изображения. После `Вот она` ландшафт начинает превращаться в тоннель; в финальном состоянии тоннель полностью сформирован.

## Product evidence

- `Хотя подождите.` — EH-P05 Products.
- `У вас ведь уже есть система.` — EH-P01 Calendar.
- `Вот она.` — EH-P04 Funnel editor.
- Финальная сборка — только реальные crops EH-P05/EH-P01/EH-P04/EH-P09.

Browser chrome отсекается. Product UI не перерисовывается и не редактируется.

## Motion

- Сцены линейные, без modulo и повторения.
- Вход product-plane: дальний z-plan, уменьшенный scale, умеренный rotateY.
- Центральная фиксация: читаемый screenshot пересекает крупный заголовок.
- Выход: плоскость проходит дальше по z-оси; следующая сцена приходит из глубины.
- Tunnel mix начинается на входе в `Вот она` и достигает 1 в финальной сцене.
- Scroll остаётся native и полностью обратимым.

## Responsive and accessibility

- Desktop: product-plane находится в центре/правее, крупный текст может выходить за края viewport как у reference.
- Mobile: один читаемый product-plane, текст максимум 3–4 строки, без horizontal overflow.
- Reduced motion: статическая вертикальная последовательность без z-flight, streaks и тоннельного ускорения.

## Explicit exclusions

- Нет копирования Mesh3D logo, зелёной палитры, брендинга или gallery content.
- Нет бесконечного headline-loop.
- Нет отдельного чёрного экрана между Hero и Section 2.
- Нет synthetic ElevenHouse UI.
