# Проверка внутреннего и внешнего отступа

Основание: замечание пользователя о разрыве между описанием тарифов и карточками. Сохраняем композицию, размеры карточек, исходные CRM-элементы и motion. Первый экран не изменён.

## Исправления

- Тарифы: заголовок → описание 20 px, описание → видимая центральная карточка 48 px, карточка → переключатель 32 px. На телефоне: 16 / 32 / 24 px.
- Пустое поле камеры вычитается из внешних отступов сцены по результату существующего расчёта проекции. Размер карточки и траектория движения не меняются. Перерасчёт через существующий ResizeObserver; в HTML fallback компенсация отключена.
- Внешние поля тарифов и FAQ: 72–112 px на компьютере, 56 px на телефоне вместо прежних 110–190 px.
- FAQ: заголовок выровнен по верху; при расположении списка под заголовком интервал 36 px, на телефоне 28 px.

## Проверенные группы

| Область | Группировка |
| --- | --- |
| Вход | Подпись и поле 8 px; поля отделены на 20 px; заголовок и форма 34 px / 28 px на телефоне. |
| Выбор функций | Текст внутри каждой ограниченной рамкой карточки сгруппирован; вся сетка отделена от описания на 34 / 28 px. |
| Девять функций | Общий шаблон: заголовок шага и описание 18 / 10 px, вводное описание и две колонки 44 / 28 px. Статус и интерфейс, интерфейс и результат по 26 px. |
| Тарифы | Исправлены двойные отступы сцены; интервалы считаются до видимой карточки. |
| FAQ | Самостоятельная секция отделена сильнее, чем её заголовок от списка; открываемый ответ остаётся внутри соответствующего вопроса. |
| Финал и футер | Кнопка и подпись составляют одну группу; документы сгруппированы в отдельную строку. Полноэкранная композиция сохранена. |

Рамка карточки также обозначает группу: правило не означает механическое увеличение всех межкарточных промежутков сверх каждого внутреннего отступа. Свободное место перед нижней кнопкой в пошаговой сцене сохраняет ранее запрошенное выравнивание по низу двух колонок.

## Проверка

- Браузер: тарифы на 1440 px и 390 px. Измерено 48.00 / 32.00 px до карточки, 32.03 / 24.02 px до переключателя.
- Визуально проверены вход, меню и один сценарий общего шаблона на компьютере/телефоне, мобильные тарифы, FAQ и финал. Остальные сценарии проверены по общим стилям, без покадрового просмотра каждого шага.
- На телефоне ширина документа 390 px при viewport 390 px; горизонтального переполнения нет.
- `npm test -- --run --exclude 'experiments/**'`: 330 тестов, 44 файла прошли.
- `npm run build` и `git diff --check` прошли. Сохраняется предупреждение сборщика о большом JS chunk.
