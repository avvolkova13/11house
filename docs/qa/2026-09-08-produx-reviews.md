# Отзывы ElevenHouse — сверка с PRODUX

Дата: 8 сентября 2026. Референс: https://www.produx.design/, секция Trusted partners / Reviews.

## Основание изменений

Сверены живой блок в браузере, вычисленные стили и публичная реализация анимации референса. Сохранены синяя палитра ElevenHouse, три существующих отзыва, монограммы и шрифт проекта. Изображения, портреты и исходный код PRODUX в проект не переносились.

| Поведение | Параметры референса и реализации |
| --- | --- |
| Горизонтальный проход | Вертикальный участок 320 высот экрана; начало top −35%, конец bottom 95%; сглаживание 1500 мс, expo.out |
| Выравнивание карточек | Общий quadratic ease-out с движением ленты; начальная ступень 10vh, на планшете и телефоне 7vh |
| Наведение | Активная карточка ×1.02; соседние ×0.98, opacity 0.5, blur 4px, brightness 0.4; переход 700 мс |
| Заголовок при наведении | Opacity 0.5, blur 4px, brightness 0.6; переход 600 мс; затемнение фона с задержкой 100 мс |
| Шкала | Семь активных штрихов; переход 350 мс с возвратом; 250 / 133 / 67 видимых штрихов при 1280 / 1024 / 390 px |
| Появление заголовка | Собственная canvas-реализация: ячейки 5 px, сдвиг слов 70 мс, раскрытие 1750 мс; на телефоне движение слов 1400 мс |
| Сенсорный ввод | Выделение после удержания 200 мс, сброс при перемещении и отпускании |

Убраны перетаскивание ленты и отдельная мобильная bounce-анимация, отсутствующие в референсе. CSS-кривые переходов воспроизводят соответствующие easing референса приближением cubic-bezier. Пиксельная маска заголовка воссоздана самостоятельно; её шум не является покадровой копией оригинала.

## Проверки

- Визуально проверены desktop 1280×720, tablet 1024×768 и mobile 390×844; также проверен блок в составе основной страницы.
- В проверенных размерах нет горизонтального переполнения документа и обрезания текста внутри карточек.
- Проверены состояния наведения, изменение размеров, движение шкалы и доступность последней карточки.
- Проверена клавиатурная навигация: стрелки, Home, End; нужный отзыв выводится в видимую область.
- Для reduced motion предусмотрены статичные карточки и обычная горизонтальная прокрутка; проверены код и стили, системная настройка в браузере отдельно не переключалась.
- RAF завершается после сглаживания и после появления заголовка; наблюдатели, события и таймеры очищаются. Canvas ограничен DPR 2. Отдельного профиля FPS на физических устройствах нет.
- `npm test -- --run --exclude 'experiments/**'`: 33 файла, 275 тестов — успешно. Экспериментальная директория исключена из проверки основного сайта из-за ранее обнаруженного отсутствующего модуля physicalDial.
- `npm run build`: успешно. Существующее предупреждение Vite о размере общего JS-бандла более 800 kB остаётся; итог 870.88 kB, gzip 240.92 kB.
- `git diff --check`: успешно.
- Сравнение CSS со снимком перед этой задачей подтвердило: изменения ограничены селекторами отзывов. Hero, общие стили, зависимости и ранее доработанный блок цен в рамках этой задачи не менялись.
