# Знакомство с функциями для нового пользователя

Выполнено уточнение от 9 сентября: каждый выбранный раздел должен объяснять назначение и пользу инструмента, а затем показывать работу анимированными фрагментами исходной CRM.

## Что изменилось

- Девять историй, 26 шагов: объяснение инструмента → действие → результат. Примеры основаны на карточке Марины Соколовой и практике Алисы Веги.
- Исходные элементы CRM показывают ввод данных, сохранение заметки, отправку ответа, построение и переключение расчётов, перенос встречи, оформление услуги, появление материалов, проверку AI-текста, планирование публикации и учёт оплаты.
- Проигрыватель работает только для выбранного раздела. Пауза, переход вперёд/назад, выбор шага на desktop и повтор доступны рядом с пояснением. Завершение не зацикливается и не открывает другой раздел.
- На телефоне текст текущего шага и управление закрепляются над фрагментом. Видимость рассчитывается с учётом этого перекрытия; таймер не продвигается, когда интерфейс нельзя рассмотреть. Скрытие вкладки и выход из видимой области останавливают время. RAF, observer и listener очищаются при выходе.
- Reduced motion показывает готовое состояние каждого действия с ручными переходами.
- SVG-расчёты мемоизированы; движение раскрытия задаётся внешней маской. Исходная геометрия сохраняется. Нумерологическая сетка последовательно подсвечивает ячейки.
- Новые элементы редактора публикации взяты из `app/content.jsx → PostEditor` архива. Сетевые отправки, расчётные backend, платежи и внешние stores не подключены. Все показанные изменения локальны.

Вход, меню выбора с его текстами, первый экран, обработчик доведения первого перехода, фон, коммерческие блоки и финальный тоннель в этой правке не изменялись. CSS ограничен выбранным сценарием.

## Проверка

- Полный рабочий набор: 315 тестов в 41 файле прошли (`npm test -- --run --exclude 'experiments/**'`). Существующий сломанный эксперимент physicalDial исключён, его файлы не менялись.
- Все 26 шагов рендерятся в начале, середине и конце. Проверены пустые поля, сохранённая заметка, перенос 11:00 → 14:00, ожидание AI-проверки, передача материалов, сумма до/после оплаты и планирование поста.
- Браузер desktop: заметка набирается; пауза удерживает точное значение и прогресс; сохранение даёт новую заметку в карточке. Обычный сценарий услуги проходит от пустых полей до карточки и конечного состояния сам, повтор возвращает его к началу.
- Браузер 390×844: пояснение закреплено вместе с управлением, фрагмент читается ниже; ширина документа 390px. Автоматическая история услуги доходит до конца.
- Браузер reduced-motion: перенос из карточки в выбор времени, сохранение 14:00; цепочка → AI-текст → подтверждение → переданные материалы; завершение и повтор.
- Read-only code review: исправлены потеря мобильного пояснения, неверное действие альтернативных кнопок, переходы вкладок. Повторная проверка не нашла Critical/Important.
- TypeScript/Vite build и `git diff --check` проходят. Существующее предупреждение Vite о крупном chunk сохраняется. Новые пакеты не устанавливались.

Во время браузерной проверки автоматическая политика заблокировала внешний переход на app.elevenhouse.ai: ограничение пользователя требует только локальной работы. Внешний сервис не использовался; проверка продолжена в отдельной вкладке 127.0.0.1.

Без коммитов, push и публикации.
