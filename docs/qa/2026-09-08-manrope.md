# Manrope — подключение

Пользователь согласовал замену Avenir Next на бесплатный Manrope по всему лендингу, включая Hero. Изменено только семейство в существующих CSS declarations, добавлены @font-face и две preload-ссылки. Размеры, толщины, letter-spacing, layout и motion Hero не менялись.

Официальные WOFF2 Google Fonts v20, три неизменённых subset-файла (Cyrillic, Latin, Latin extended с ₽), variable axis 200–800. Всего 54 456 байт. Лицензия SIL OFL 1.1 сохранена рядом с файлами и включена в public assets для production. Источники перечислены в src/assets/fonts/manrope/README.md.

Текст canvas тарифов и заголовка отзывов ждёт загрузки Manrope. Ошибка загрузки разрешает системный fallback; размонтированный заголовок не запускает отложенную анимацию.

Проверено:
- 283 теста / 35 файлов проходят, включая ожидание fonts.load и обработку ошибки.
- GITHUB_ACTIONS=true npm run build проходит. Все три URL /11house/assets/*.woff2 разрешаются в существующие файлы сборки; лицензия тоже присутствует.
- Browser FontFaceSet: все три лица loaded; проверки толщин 250, 400, 500, 650, 800 с текстом АаЁё₽ElevenHouse вернули true.
- ResourceTiming: запросы только к локальным WOFF2; 14 500 + 15 120 + 24 836 байт. Внешних Google Fonts запросов нет.
- Hero визуально проверен при 1280×720; шапка и заголовок помещаются. CSS computed family в заголовках секций и кнопках — Manrope.
- Временный диагностический HTML удалён.

Осталось прежнее предупреждение Vite о JS chunk больше 800 КБ. Зависимости не менялись; commit/push/deploy не выполнялись.
