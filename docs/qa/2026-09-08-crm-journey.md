# CRM journey — локальная проверка

**Архив предыдущей итерации.** После уточнения пользователя полные страницы заменены фрагментами. Актуальная проверка: `2026-09-08-source-fragments.md`.

Дата: 2026-09-08. Реализация согласована пользователем. Без коммитов, push, публикации и новых зависимостей.

## Результат

10 последовательных глав, 34 состояния интерфейса. Элементы перенесены из JSX/CSS архива в изолированные React/TypeScript и SVG-компоненты, источники указаны в комментариях и `docs/CRM_LANDING_AUDIT.md`. Данные демонстрационные, связаны общей историей Алисы Веги и Марины Соколовой. Формы, оплата, сообщения и звонок не создают внешних действий.

Первый заголовок разделён на верхнюю левую и нижнюю правую части. Оригинальный фон используется непрерывно; новый адаптер разделяет внутренние шаги и межглавные пролёты. Отзывы, тарифы и FAQ стоят перед оригинальным синим тоннелем с заключительным текстом.

## Браузер

Проверено через локальный `http://localhost:5173/`, без внешних отправок.

- 1280×720: новый первый экран, регистрация → подтверждение → кабинет, настройка, клиент и заметки, натальная карта и бодиграф, автоматизация и AI-проверка. Финальный синий тоннель визуально проверен после прокрутки финала.
- 390×844: регистрация и переключение скроллом после прочтения формы, карты и автоматизация; горизонтальная ширина документа равна viewport.
- 320×740: карточка клиента, DOM-геометрия всех новых глав — нет элементов за горизонтальными границами. Есть прежнее ограничение шапки, см. ниже.
- 390×640: после изменения только высоты окна резерв панели регистрации остаётся 896px, высота главы 1676px; шаг не перескакивает.
- Reduced motion через dev-параметр `?reduced-motion`: главы в обычном потоке (`position: relative`), доступны переключатели; проверен переход к заметкам клиента.
- Прямые ссылки на главы и повторная загрузка в середине истории работают. Навигация переносит фокус к целевому разделу; невидимые главы исключены через inert.
- Тариф переключается на Pro с ценой 1 990 ₽; FAQ раскрывает исходный ответ.
- В просмотренных сценах браузерные error/warn logs пусты.

## Исправления по результатам проверки

- Мобильный контент уплотнён: формы, компактная карточка, календарь, SVG и цепочка из пяти узлов.
- Натальные символы используют текстовое представление вместо цветных emoji.
- Зарезервирована максимальная высота главы, исключено преждевременное переключение до прочтения высокой панели.
- Смена только высоты окна самостоятельно восстанавливает резерв, без зависимости от ResizeObserver.
- Автоматический индекс и React state синхронизируются после выхода из поля ввода.
- Исправлены фокус навигации, доступность невидимых сцен и ссылка перехода после последней главы.
- Независимое финальное code review: Critical/Important нет после исправлений.

## Сохранность фона и границы проверки

`src/styles.css`, зависимости, шейдеры, StarField, NebulaField, PostProcessing, PointerTrail, cosmic motion helpers и исходные настройки рендера не изменены. В `CosmicScene.ts` изменён только TypeScript-тип входа адаптера. В `CosmicHero.tsx` добавлен режим фонового слоя, исходная сцена и lifecycle сохранены. Характер движения прежний, запуск пролётов привязан к новой истории.

На 320px исходная CTA-кнопка шапки выходит вправо. Шапка обозначена locked в AGENTS.md; её прежние размеры и responsive-правила не исправлялись в этой задаче. На 390px кнопка помещается.

Исходное предупреждение Vite о крупном JS-chunk сохраняется. Нового фонового WebGL renderer не добавлено; существующий renderer тарифов и 2D pointer canvas сохранены. Аппаратные замеры FPS/GPU, реальная мобильная клавиатура, screen reader и принудительная потеря WebGL context в этой проверке не эмулировались. Обратное движение проверено unit-тестами, без отдельного браузерного прогона всей истории снизу вверх.
