Analytical reference board · Section 03

Один клиент. Один непрерывный контекст.

История строится как один pinned product stage: не шесть feature-блоков, а последовательная смена фокуса вокруг Анны. Маркетинговый слой управляет камерой; продуктовые слои остаются точными screenshots.

Reference ownership

R5 + R10/R12

Дисциплина UI и причинный motion

R5 определяет чистые рамки, readable density и иерархию product crops. R10/R12 используются только как принцип: следующее состояние появляется из смысла предыдущего, без случайного fade-up. Визуальная форма и product anatomy берутся не из них, а из ElevenHouse.

ElevenHouse evidence · exact product states

One stage · six focus states

01

Выбор

Каталог остаётся целым; одна реальная консультация выходит вперёд. Никакого public page или checkout.

02

Контекст

Анна — semantic anchor. Вокруг неё только подтверждённые рабочие контексты, без fake node graph и обещания автосинхронизации.

03

Подготовка

Natal pre-calc, Numerology и Matrix разрешены по inventory. В текущем workspace доступен точный asset Numerology; отсутствующие binaries не заменяются подделками.

04

10:00

Неделя отступает, инспектор записи становится главным. Стоп на «Войти в сессию»; call UI не существует в evidence.

05

После

Темп замедляется. Астродневник показывает возможность продолжать работу, но не притворяется журналом той же записи.

06

Сценарий

Partially blocked: исходный prompt обрывается. Показываем только редактор и дословную утверждённую фразу; execution story не достраиваем.

Implementation decision

В код идёт

Одна длинная reversible sticky-сцена; persistent anchor «Анна»; последовательные camera moves; реальные P05/P01/P07/P09/P04; mobile показывает один state за раз; reduced-motion превращает историю в спокойную вертикальную последовательность.

Не идёт в код

Public profile, checkout, purchase confirmation, populated CRM profile, automatic relationship chain, calculated Natal, Human Design, video-call UI, auto-created diary, execution funnel и любой текст после физически обрезанного фрагмента задания.
